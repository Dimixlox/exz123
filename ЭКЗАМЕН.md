# Инструкция: развернуть проект на экзамене

---

## ШАГ 1 — Создать новую папку для проекта

Открыть терминал и создать чистую папку:

```
mkdir project
cd project
git init
```

---

## ШАГ 2 — Открыть Claude Code

В терминале внутри папки запустить:

```
claude
```

Вставить текст ТЗ целиком и написать:

```
Вот моё ТЗ: [вставить текст ТЗ]

Создай полноценный веб-проект на стеке Node.js, Express, Sequelize,
PostgreSQL, JWT. Нужны:
- регистрация и авторизация пользователей
- личный кабинет
- форма заявки
- панель администратора
- адаптивный фронтенд (HTML + CSS + JS)
Сделай минимум 3 коммита с разными датами.
```

Клод создаст весь проект с нуля под новое ТЗ.

---

## ШАГ 3 — Создать базу данных

Открыть PostgreSQL:

```
"C:\Program Files\PostgreSQL\17\bin\psql" -U postgres
```

В консоли psql (название базы — любое, главное потом указать в .env):

```sql
CREATE DATABASE my_project_db;
\q
```

---

## ШАГ 4 — Настроить .env

В файле `.env` указать свои данные PostgreSQL:

```
DB_NAME=my_project_db
DB_USER=postgres
DB_PASSWORD=12345
```

---

## ШАГ 5 — Установить зависимости и запустить

```
npm install
```

```
npm start
```

Открыть браузер: `http://localhost:3000`

---

## ШАГ 6 — Залить на GitHub

Создать репозиторий на github.com (кнопка **+** → New repository, **без** галочек на README).

```
git remote add origin https://ЛОГИН:ТОКЕН@github.com/ЛОГИН/ИМЯ_РЕПО.git
git push -u origin master
```

> Токен: GitHub → Settings → Developer settings → Personal access tokens
> → Tokens (classic) → Generate → галочка **repo**
