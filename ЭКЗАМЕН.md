# Инструкция: как развернуть и переделать проект на экзамене

---

## ШАГ 1 — Скачать проект с GitHub

Открыть терминал (папка не важна) и выполнить:

```
git clone https://github.com/Dimixlox/exz.git
```

```
cd exz
```

---

## ШАГ 2 — Установить зависимости

```
npm install
```

---

## ШАГ 3 — Создать базу данных

Открыть PostgreSQL:

```
"C:\Program Files\PostgreSQL\17\bin\psql" -U postgres
```

В консоли psql:

```sql
CREATE DATABASE conferences_db;
\q
```

> Если нужна другая база под новую тему — назови её как хочешь,
> потом укажи в .env

---

## ШАГ 4 — Настроить .env

Открыть файл `.env` в папке проекта и проверить:

```
DB_NAME=conferences_db
DB_USER=postgres
DB_PASSWORD=12345
```

Поменять только если нужно другое имя базы или другой пароль от PostgreSQL.

---

## ШАГ 5 — Запустить проект

```
npm start
```

Открыть браузер: `http://localhost:3000`

Всё работает — идём дальше.

---

## ШАГ 6 — Передать Клоду новое ТЗ

Открыть Claude Code в терминале этой же папки (`claude`) и написать примерно так:

```
У меня новое ТЗ для экзамена. Вот оно: [вставить текст ТЗ целиком]

Нужно переделать этот проект под новую тему, сохранив весь стек
(Express, Sequelize, PostgreSQL, JWT). Измени:
- названия и описания сущностей
- поля моделей под новую предметную область
- тексты на страницах
- цветовую тему если нужно
- логику под новые статусы/роли если отличаются
```

Клод сам разберётся что менять — он знает структуру этого проекта.

---

## ШАГ 7 — Сделать коммиты

После того как Клод переделал проект, в терминале:

```
git add .
git commit -m "feat: переработка под новое ТЗ"
```

Если нужны ещё коммиты с разными датами — попросить Клода:
```
сделай мне 3 новых коммита с разными датами по проекту
```

---

## ШАГ 8 — Залить на GitHub

```
git push
```

Если репозиторий новый (другой аккаунт или другое название):

```
git remote set-url origin https://ЛОГИН:ТОКЕН@github.com/ЛОГИН/ИМЯ_РЕПО.git
git push -u origin master
```

> Токен создаётся на GitHub → Settings → Developer settings →
> Personal access tokens → Tokens (classic) → Generate → поставить галочку **repo**

---

## Что говорить Клоду если он не знает структуру проекта

Если начинаешь новый чат и Клод не помнит проект — дать ему такой контекст:

```
Проект на стеке: Node.js, Express, Sequelize, PostgreSQL, JWT.
Структура:
- server.js — точка входа, Express + сидирование БД
- config/database.js — подключение к PostgreSQL
- models/ — модели Sequelize (User, Room, Booking, Review)
- middleware/auth.js — JWT авторизация
- routes/ и controllers/ — REST API
- public/ — статический фронтенд (HTML + CSS + JS без фреймворков)

Вот новое ТЗ: [вставить ТЗ]
```
